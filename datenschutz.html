Was die Anwendung tut

KI-Leon ist ein privates Werkzeug, das ausschließlich vom Verantwortlichen selbst genutzt wird. Es lädt über die YouTube Data API Videos auf die eigenen YouTube-Kanäle des Verantwortlichen hoch, nachdem er jedes Video einzeln freigegeben hat.

Welche Daten verarbeitet werden

  • Ein OAuth-Zugangstoken für die eigenen YouTube-Kanäle. Es wird nur auf dem eigenen Rechner des Verantwortlichen gespeichert.
  • Name, ID und Handle des eigenen YouTube-Kanals, um zu prüfen, dass auf den richtigen Kanal hochgeladen wird.
  • Die hochgeladenen Videos sowie deren Titel, Beschreibung und Untertitel.

Daten anderer Personen werden nicht erhoben. Es werden keine Daten an Dritte weitergegeben, verkauft oder für Werbung genutzt. Es gibt keine Cookies und kein Tracking.

Nutzung von Google-Diensten

Die Anwendung nutzt die YouTube API Services. Es gelten die Nutzungsbedingungen von YouTube und die Datenschutzerklärung von Google. Der Zugriff lässt sich jederzeit unter myaccount.google.com/permissions widerrufen; danach löscht der Verantwortliche das gespeicherte Token.

Die Nutzung von Daten aus Google-APIs hält sich an die Google API Services User Data Policy, einschließlich der Anforderungen zur eingeschränkten Nutzung (Limited Use).

Nutzung von Meta-Diensten (Instagram)

Für Instagram nutzt die Anwendung die Instagram Graph API über Facebook Login for Business. Gespeichert werden nur auf dem eigenen Rechner des Verantwortlichen: Zugangstokens der eigenen Facebook-Seiten, ID und Benutzername der eigenen Instagram-Konten. Veröffentlicht werden nur Videos, die der Verantwortliche einzeln freigegeben hat. Es gelten die Datenschutzrichtlinie von Meta und die Nutzungsbedingungen von Instagram.

Löschung der Daten

Der Zugriff lässt sich jederzeit in den Facebook-Einstellungen unter „Business-Integrationen“ bzw. „Apps und Websites“ entfernen. Auf Wunsch (Mail an die oben genannte Adresse) löscht der Verantwortliche alle gespeicherten Tokens und Kontodaten.
